# 陕北 + 宁夏 自然景观自驾环线（5 天）

洛川槐柏镇出发的一条 5 天自驾环线，只走自然景观。

**在线阅读** → https://wenlonn.github.io/-shaanbei-trip/

## 路线

```
槐柏镇 → 壶口瀑布 + 黄河乾坤湾 → 靖边波浪谷 + 盐池哈巴湖
   → 沙坡头（整天）+ 中卫 66 号公路 → 海原南华山 → 崆峒山 → 到家
```

景观主线：**黄河的水 → 黄河的弯 → 丹霞的纹 → 荒漠的湖 → 沙漠撞黄河 → 山地的秋**

全程约 1817 km / 驾驶约 27.7 h，宿延川县城、盐池县城、中卫城区、平凉城区。

## 这份行程的特点

- **带省·市·县三级标注的路线地图**：路线几何取自 OSRM 实际路网规划，标出每天在哪个省、哪个市、哪个县
- **车程为实测值**：按百度地图实际导航时长填写（比理论路网规划略长）；里程为 OSRM 路网实测
- **按光线排时段**：每个景点标注最佳光线窗口（比如波浪谷的一线天只在 10:00-12:00 成立、乾坤湾非下午侧光不可），行程顺序是围着光线排的
- **每个景点按 4 小时量安排**，沙坡头单独占一整天
- **中途吃饭/住宿落点写清楚**：每天在哪个镇吃午饭、住哪个县城、车程多少，都在表里
