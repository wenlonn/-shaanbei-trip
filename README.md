# 陕北 + 宁夏 自然景观自驾环线（5 天）

洛川出发的一条 5 天自驾环线，只走自然景观。

**在线阅读** → https://USERNAME.github.io/shaanbei-trip/
*（部署后把 `USERNAME` 换成你的 GitHub 用户名）*

## 路线

```
洛川 → 壶口瀑布 + 黄河乾坤湾 → 靖边波浪谷 + 盐池哈巴湖
   → 红寺堡罗山 + 沙坡头 → 腾格里沙漠 + 海原南华山 → 崆峒山 → 洛川
```

景观主线：**黄河的水与弯 → 丹霞的纹 → 荒漠的湖 → 沙漠的湖 → 山地的秋**

全程约 1660 km，除返程末段外单段车程都在 2.4 小时内。

## 这份行程的特点

- **每段车程实测**：里程和车程用 OSRM 路径规划逐段算过，不是估的
- **按光线排时段**：每个景点标注最佳光线窗口（比如波浪谷的一线天只在 10:00-12:00 成立，甘泉大峡谷必须卡正午），行程顺序是围着光线排的
- **长途都拆开了**：每个断点都落在一个值得停的地方，不是服务区
